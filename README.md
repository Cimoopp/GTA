# 🚗 Mini GTA — 3D-игра для Android (Godot 4)

Мини-версия GTA на движке **Godot 4**: открытый город, ходьба от третьего лица,
машины, стрельба, пешеходы, миникарта. Внешние ассеты не нужны — весь мир
строится из примитивов прямо в коде.

## 📁 Что в проекте

| Файл | Назначение |
|:---|:---|
| `project.godot` | настройки проекта (мобильный рендерер, горизонтальный экран) |
| `Main.tscn` | главная сцена, к ней подключён `main.gd` |
| `main.gd` | вся игра: мир, игрок, машины, пешеходы, пули, HUD, миникарта |
| `export_presets.cfg` | готовый профиль экспорта в APK |
| `.gitignore` | чтобы в репозиторий не попадал кэш редактора |

## 🎮 Управление

**На компьютере**

| Клавиши | Действие |
|:---|:---|
| WASD | идти |
| Shift | бег |
| Space | прыжок |
| мышь | обзор |
| ЛКМ | выстрел |
| E | сесть в машину / выйти |
| W / S, A / D (в машине) | газ-тормоз, руль |

**На телефоне**

- джойстик слева внизу — движение;
- свайп по правой части экрана — обзор;
- кнопки 🔫 (выстрел), ⤒ (прыжок), 🚗 (машина);
- за рулём вместо них появляются 🚀 газ, 🛑 тормоз, ◀ ▶ руль.

## 🌍 Что есть в мире

- сетка дорог 10 × 10 кварталов (около 200 × 200 м);
- здания-коробки случайной высоты и цвета;
- деревья и фонари вдоль улиц;
- 8 машин: часть припаркована, часть ездит сама и объезжает препятствия;
- 16 пешеходов, которые ходят по тротуарам и исчезают от попаданий;
- полоса здоровья, счётчик патронов (бесконечные, но с перезарядкой);
- миникарта: игрок (голубая точка), машины (красные), пешеходы (зелёные), здания (серые);
- физика: гравитация, столкновения со зданиями и машинами, наезд отнимает здоровье.

## 🔨 Как собрать APK (один раз настроить)

1. Установи **Godot 4.3** или новее: https://godotengine.org/download
2. Открой Godot → **Import** → укажи файл `project.godot` из этой папки.
3. Открой **Project → Export…** → выбери пресет **Android** (он уже в проекте).
4. Если Godot пишет, что нет Android SDK — нажми **Editor Settings → Export → Android**
   и укажи пути к SDK, JDK 17 и debug keystore (Godot сам предлагает создать его).
   Проще всего воспользоваться кнопкой **Install Android Build Template** и мастером
   настройки — он скачивает всё нужное автоматически.
5. Нажми **Export Project…**, сохрани файл как `mini-gta.apk`.
6. Перекинь APK на телефон и установи (разреши «Установка из неизвестных источников»).
